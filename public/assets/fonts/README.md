# فونت B Nazanin (فونت اصلی سایت)

این پوشه محل قرارگیری فایل‌های فونت **B Nazanin** برای هاستینگ سایت است.

## روش کار فعلی
در حال حاضر فونت B Nazanin از طریق دستور `local()` در فایل‌های CSS
(`public/assets/css/style.css` و `admin.css`) فراخوانی می‌شود. این یعنی اگر
B Nazanin روی کامپیوتر بازدیدکننده (ویندوز فارسی) نصب باشد، به‌صورت خودکار
و بدون هیچ دانلودی استفاده خواهد شد.

## برای هاست کردن (توصیه شده)
تا مطمئن شوید فونت روی همه دستگاه‌ها (موبایل، لینوکس، مک) یکسان دیده می‌شود،
فایل‌های فونت را در همین پوشه قرار دهید:

- `BNazanin.woff2`  (نسخه معمولی)
- `BNazanin.woff`
- `BNazanin.ttf`
- `BNazanin-Bold.woff2` (نسخه بولد)
- `BNazanin-Bold.woff`
- `BNazanin-Bold.ttf`

مراحل:
1. فونت‌ها را از فرمت TTF با یک مبدل آنلاین (مثلاً transfonter / cloudconvert)
   به WOFF2 و WOFF تبدیل کنید.
2. فایل‌ها را با همین نام‌ها در این پوشه کپی کنید.
3. تمام! دیگر هیچ تنظیم اضافه‌ای لازم نیست؛ `@font-face` قبلاً آماده است.

اگر فایل‌ها نباشد، سایت بدون مشکل با فونت جانشین Vazirmatn (از گوگل فونتس)
کار خود را ادامه می‌دهد.
